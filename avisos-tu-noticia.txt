# Avisos, modal, banner y widgets — Tu Noticia v9.3
# --------------------------------------------------
# CÓMO FUNCIONA:
# - La app revisa este archivo CADA 10 MINUTOS y también cada vez
#   que se abre. Solo descarga este .txt (no descarga las noticias).
# - NOTIFICACIÓN: si "mensaje" tiene texto, la app envía UNA
#   notificación push con ese texto y no la repite hasta que lo
#   cambies. Si "mensaje" está VACÍO, no hay notificación.
# - MODAL EN PANTALLA: si "modal_mensaje" tiene texto, la app
#   muestra UNA VENTANA en la pantalla al abrirla, con el título,
#   el texto y el botón que pongas aquí. No se repite hasta que
#   cambies el texto. Si "modal_mensaje" está VACÍO, no hay modal.
# - BANNER: si "banner_texto" tiene texto, aparece una tarjeta
#   arriba de las noticias, con el título y el texto que pongas.
#   Cada usuario puede cerrarla con la X; vuelve a aparecer solo
#   si cambias el texto. "banner_enlace" es opcional: si pones una
#   URL, al tocar el banner se abre esa página.
# - WIDGETS: tarjetas que aparecen arriba de las noticias.
#   Pon "si" para activar y "no" (o vacío) para apagar:
#   widget_clima = clima de hoy en La Habana
#   widget_tasas = dólar y euro del mercado informal
#   widget_efemeride = un hecho de hoy en la historia
# - Para activar algo: escribe el texto, guarda y sube el archivo
#   a GitHub. Para pararlo: vacía el campo o pon "no".
#
# REGLAS DEL ARCHIVO:
# - Una opción por línea, con el formato clave=valor (sin espacios
#   alrededor del =).
# - Las líneas que empiezan con # son comentarios y se ignoran.
# - NO cambies los nombres de las claves.
# - "mensaje" y "modal_mensaje" pueden tener hasta unos 200 caracteres.
# - "enlace" es opcional: si lo dejas vacío, al tocar la notificación
#   solo se abre la app. Si pones una URL, al tocarla se abre esa
#   página en el navegador.
# - "modal_boton" es el texto del botón del modal (si lo dejas vacío,
#   dice "Entendido").
# - "modal_enlace" es opcional: si pones una URL, al tocar el botón
#   del modal se abre esa página. Si lo dejas vacío, el botón solo
#   cierra el modal.
# --------------------------------------------------
